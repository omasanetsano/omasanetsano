## Selected work

### [BookDex](https://bookdexhub.com)
**Multi-tenant booking, deposits and invoicing for service businesses.** Solo build, 2025 to now, in production.

Each business gets a public booking page, plus a dashboard for bookings, clients, staff and invoices. Tenant separation is enforced with PostgreSQL Row Level Security. Booking and payment changes write signed webhook events in the same database transaction, and CI runs tests, type checks and secret scanning on every change.

`React` `TypeScript` `Supabase` `PostgreSQL` `Deno Edge Functions` `Cloudflare Workers`

*The source is private. Happy to walk through it in an interview.*

![BookDex](https://raw.githubusercontent.com/omasanetsano/Portfolio/main/public/projects/bookdex-site.jpg)
