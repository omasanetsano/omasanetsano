### 🚀 About Me

I'm **Omasanjuwa Andrew Etsano**, an early-career software engineer in Abuja, Nigeria, focused on full-stack web development.

I build and run **[BookDex](https://bookdexhub.com)**, a booking and invoicing product for service businesses in Nigeria.
